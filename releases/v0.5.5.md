Lomi 0.5.5 improves account recovery, remote workspace sharing, and everyday workspace navigation.

- Recover an unreadable saved account session from Account settings. Sign In opens the recovery options, and development builds use separate account storage from the installed app.
- Remote sharing controls remain disabled until the account is signed in. Sharing confirmations, status, and errors are clearer, and shared workspace metadata includes tabs and terminal split layouts.
- Personalize workspaces with icons, images, and colors, and see repository summaries in the workspace list. The Agents dialog limits terminal launches to the available pane space.
- Improve terminal glyph rendering and make file-drop borders easier to see in split terminals.
- Harden file previews and Git observations, bound AI response streams, update patched dependencies, and stage the bundled runtime atomically.

Remote hosting remains enabled only on macOS Apple Silicon, with a total limit of 32 active desktop terminals across all workspaces. Live channels use end-to-end encryption; offline mailbox access remains disabled.
