Lomi 0.5.3 declares compatibility with the safe remote control renewal protocol.

- Native remote requests identify support for atomic lease renewal. Updated servers require this protocol before admitting a desktop host to live sharing.
- If a server requires a newer desktop, Lomi displays “Update Lomi to share workspaces remotely.” Account sign-in remains separate from remote sharing.
- This release includes the 0.5.2 renewal fix: valid renewal extends only the existing lease, while expired or locally preempted control remains observing until the browser explicitly requests control again.

Remote hosting remains enabled only on macOS Apple Silicon, with a total limit of 32 active desktop terminals across all workspaces. Live channels use end-to-end encryption; offline mailbox access remains disabled.
