Lomi 0.5.2 fixes remote terminal control renewal after local takeover.

- Local typing keeps priority over browser control. An expired or preempted browser lease cannot regain control through automatic renewal; the browser must request control again.
- Valid renewal extends only the existing lease. Rejected renewal leaves the browser observing live terminal output.

Remote hosting remains enabled only on macOS Apple Silicon, with a total limit of 32 active desktop terminals across all workspaces. Live channels use end-to-end encryption; offline mailbox access remains disabled.
