Lomi 0.5.1 adds live remote access to shared workspaces from the browser.

- Share a workspace from its context menu. Its terminal tabs and split panes become available together, and new terminals join the shared workspace automatically.
- Sign in with the same account to enroll the browser device and connect to your shared workspaces. Stop sharing to revoke browser access.
- Keep terminals available while Lomi runs in the background, with live output, keyboard input, and workspace updates.
- Remote hosting is currently enabled only on macOS Apple Silicon. Intel macOS, Windows, and Linux remain gated pending native qualification.
- Remote hosting supports up to 32 active desktop terminals in total across all workspaces. A workspace containing a terminal beyond that limit cannot be shared.

Live channels use end-to-end encryption. Offline mailbox access remains disabled. Shared terminals remain live only while the desktop app and host connection are running.
