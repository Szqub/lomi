Lomi 0.5.6 hardens saved application settings and the plugin build toolchain.

- Save application settings with exclusive temporary files and atomic replacement. Reject symlink and nonregular destinations, preserve prior settings on failure, and restrict settings file permissions on macOS and Linux.
- Bundle and verify the safe plugin SDK build helper, including checks that plugin builds stay inside their project and preserve unrelated files.
- Require native security regressions on macOS Apple Silicon, macOS Intel, Linux x64, and Windows x64 before release packaging and publication.
- Group CLI usage by account and place Source Control on the right by default.

Remote hosting remains enabled only on macOS Apple Silicon, with a total limit of 32 active desktop terminals across all workspaces. Live channels use end-to-end encryption; offline mailbox access remains disabled.
