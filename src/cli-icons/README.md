# CLI icons

SVG assets downloaded from the [Iconify API](https://iconify.design/docs/api/queries/)
on September 24, 2026 and verified byte-for-byte against the same API URLs on
September 29, 2026. They are bundled with Lomi and require no network requests
at runtime. `CliAgentIcon` renders single-color marks as CSS masks so they follow
the active theme.
